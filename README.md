> **CapsSwitch** — сверхбыстрый, легковесный и полностью автономный аналог Punto Switcher для Windows 10/11, написанный на современном C++20 с использованием нативного Win32 API и Microsoft UI Automation.

---

## 🚀 Ключевые преимущества и производительность

- **Нулевой input lag:** Низкоуровневый хук `WH_KEYBOARD_LL` выполняется в среднем за **< 10 микросекунд**. События клавиатуры немедленно передаются в асинхронную очередь и обрабатываются в фоновом воркере. Системная очередь ввода никогда не блокируется.
- **Минимальное потребление памяти:** Потребление оперативной памяти в фоне составляет **~1.6–3 MB RAM** (что в 10 раз ниже лимита в 25 MB).
- **100% переносимость (Portable Mode):** Единый бинарник `CapsSwitch.exe` (~1 MB) со статически слинкованным рантаймом. Никаких внешних зависимостей, DLL или установки .NET / VC++ Redistributable. Готов к запуску прямо с USB-флешки.
- **Локальная конфигурация:** Файл `config.json` создается и считывается строго в каталоге рядом с `.exe`. Приложение не засоряет `%APPDATA%`, `%LOCALAPPDATA%` или реестр (за исключением опционального флага автозапуска).
- **Вшитые ресурсы:** Все иконки, манифесты DPI Awareness, n-граммы и словари запечены внутрь бинарника на этапе компиляции.

## 💡 Функциональные возможности

### 1. Автопереключение раскладки (Auto-Switch)
- Автоматически распознает ошибочно набранные слова:
  - Русский текст, набранный на английской раскладке (например, `ghbdtn` $\rightarrow$ `привет`, `cghjcbk` $\rightarrow$ `спросил`, `ctujlyz` $\rightarrow$ `сегодня`).
  - Английский текст, набранный на русской раскладке (например, `руддщ` $\rightarrow$ `hello`, `цшер` $\rightarrow$ `with`, `еру` $\rightarrow$ `the`).
- Проверка невозможных биграмм и сочетаний (фонотактический анализ):
  - Позиции букв `ъ`, `ь`, `ы` в начале слов.
  - Сочетания `ъ` с согласными (`ът`, `ъп`, `ър` и др.), гласные перед `ъ`.
  - Кластеры из 4+ согласных в английском языке и слова без гласных.
  - Сочетания `цш`, `ддщ`, `ьф`, `кщь`, `ащк`, `ршы` и др.
- Корректная замена слова через `SendInput`: отправка $\text{Backspace} \times N$, переключение раскладки окна и повторный ввод исправленного слова в кодировке Unicode (`KEYEVENTF_UNICODE`).

### 2. Защита полей паролей (Password Guard)
- Многоуровневая детекция полей со скрытым вводом:
  - **Win32 API:** проверка стиля `ES_PASSWORD` и сообщения `EM_GETPASSWORDCHAR`.
  - **Microsoft UI Automation:** запрос свойства `UIA_IsPasswordPropertyId` через COM-интерфейс `IUIAutomation`.
- Полная остановка буферизации символов при нахождении фокуса в поле ввода пароля (пароли никогда не анализируются и не сохраняются в памяти).
- Автоматическое мгновенное переключение раскладки на **английскую (EN)** при входе в поле пароля.

### 3. Переназначение и умные действия клавиши Caps Lock
- **Переключение раскладки:** Полный перехват и подавление стандартного триггера фиксации регистра Caps Lock в Windows (предотвращает случайный ввод капсом). Использование одиночного нажатия Caps Lock как мгновенного хоткея для циклического переключения раскладки (**RU $\leftrightarrow$ EN**).
- **Перевод по двойному нажатию (2x Caps Lock):** Быстрый двойной клик по клавише Caps Lock автоматически переводит:
  - **Выделенный фрагмент текста** (если текст выделен в активном окне).
  - **Последнее набранное слово** (если текст не выделен).
  - Программа автоматически определяет язык исходного фрагмента, выполняет перевод (RU $\leftrightarrow$ EN), заменяет текст и мгновенно переключает раскладку на нужный язык. При этом содержимое буфера обмена пользователя сохраняется и восстанавливается!
- Возможность раздельного включения/выключения опций в настройках.

### 4. Системный трей Windows 10/11
- Динамическая иконка в трее (Notification Area), отображающая текущую раскладку активного окна:
  - 🔵 **EN** — синий бейдж Fluent Design для английского языка.
  - 🔴 **RU** — красный бейдж Fluent Design для русского языка.
  - ⏸ **||** — серый бейдж при приостановке работы.
- Контекстное меню трея (по правому клику):
  - ⚙️ **Настройки** — открытие окна параметров.
  - ⏸ **Приостановить работу / Возобновить работу** — временное отключение хука.
  - ❌ **Выход** — корректное завершение приложения.
- Клик левой кнопкой мыши открывает/скрывает окно настроек.

### 5. Окно настроек (Windows 11 Fluent Dark UI)
- Современный минималистичный темный интерфейс с поддержкой `DWMWA_USE_IMMERSIVE_DARK_MODE`.
- Плавные тумблеры-переключатели (Toggle Switches) для каждого параметра.
- Управление списком процессов-исключений (игры, консоли, терминалы).

## ⚙️ Формат конфигурации (`config.json`)

Файл создается автоматически в каталоге с программой:

```json
{
  "auto_switch": true,
  "caps_lock_switch": true,
  "double_caps_convert": true,
  "password_guard": true,
  "autostart": false,
  "exclusions": [
    "cs2.exe",
    "dota2.exe",
    "valorant.exe",
    "cmd.exe",
    "powershell.exe",
    "windowsterminal.exe"
  ]
}
```

## 🔨 Сборка из исходного кода

### Вариант 1. Сборка через `build.bat` (Рекомендуется)

1. Убедитесь, что установлен компилятор GCC (например, через `w64devkit` или MinGW-w64).
2. Запустите в корневой папке проекта:
   ```cmd
   build.bat
   ```
3. Скрипт соберет `CapsSwitch.exe` с максимальными оптимизациями (`-std=c++20 -O3 -s -mwindows -static`).

### Вариант 2. Сборка через CMake

```cmd
mkdir build
cd build
cmake .. -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Release
cmake --build .
```

## 📦 Быстрый старт (Portable)

1. Скачайте `CapsSwitch.exe` из раздела [Releases](https://github.com/M0ntang/CapsSwitch/releases).
2. Поместите файл в любую папку (или на флешку) и запустите.
3. В системном трее появится иконка активного языка.
4. Для входа в настройки нажмите на иконку в трее или запустите `CapsSwitch.exe --settings`.
